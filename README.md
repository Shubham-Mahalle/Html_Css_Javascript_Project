# Task Portal - Student Task Management Project

Task Portal is a simple beginner-level web application created to practice **HTML5, CSS3, and JavaScript fundamentals**.

The project contains a navigation bar, Login and Sign Up forms, student profile, task manager, task editing, task completion, Local Storage, and logout functionality.

## Project Overview

Task Portal is designed as a small student workspace where users can:

- Create a student account
- Login using email and password
- View their profile
- Add tasks
- Mark tasks as completed
- Undo completed tasks
- Edit tasks
- Delete tasks
- View the total number of tasks
- Logout from the portal

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Flexbox
- CSS Grid
- HTML5 Form Validation

## Features

### 1. Login and Sign Up

The application provides Login and Sign Up tabs.

The Sign Up form allows the user to enter:

- Name
- Email
- Password
- Age
- Course
- Gender
- Skills

The Login form requires:

- Email
- Password

### 2. Student Registration

Users can create an account by entering their personal and educational information.

Available courses include:

- Computer Science
- B.Tech
- BCA
- BBA

Users can also select their gender using radio buttons and their skills using checkboxes.

### 3. Student Authentication

After creating an account, the user can log in using their registered email and password.

The application checks the stored account information before displaying the Task Portal.

### 4. Student Profile

The **My Profile** section displays the logged-in student's information.

It includes:

- Name
- Email
- Age
- Course
- Gender
- Skills

### 5. Task Manager

The Task Manager allows users to create and manage their study tasks.

Users can:

- Add a task
- Complete a task
- Undo a completed task
- Edit a task
- Delete a task

### 6. Complete and Undo Tasks

Users can mark a task as completed by clicking the **Complete** button or the task name.

A completed task is displayed with a line-through effect.
